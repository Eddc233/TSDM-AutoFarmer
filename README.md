### 一个每日自动签到和打工的工作流

只需把大象关进冰箱就能用了：
1. fork此项目
2. 进入 Settings → Secrets and variables → Actions，创建一个名为 TSDM_COOKIE 的 Secret，填入你的cookie  
3. 进入 Actions 选项卡并运行工作流
